Install DENO RTX VFX for ComfyUI

Use this guide when the DENO RTX Video Super Resolution node says NVIDIA RTX VFX is missing. You do not need to understand technical setup details. Just follow each step and check what is shown on screen.

Close ComfyUI first. The installer must run while every ComfyUI window and process is closed.
Use only the official download link on this page. Do not run BAT files from mirrors, reuploads, Discord attachments, or random websites.
The installer uses NVIDIA's official package path. It prepares nvidia-vfx from https://pypi.nvidia.com for the ComfyUI app you confirm.

Quick checklist

  1. Close ComfyUI.
  2. Open ComfyUI\custom_nodes\deno-custom-nodes\tools.
  3. Put the installer ZIP there.
  4. Extract it inside tools.
  5. Run the BAT from that tools folder.
  6. Confirm the shown ComfyUI location.
  7. Wait for INSTALL COMPLETE.
  8. Restart ComfyUI.

Step-by-step installation

Do not skip ahead. Each step has one action and one check.

1. Open this folder first ComfyUI\custom_nodes\deno-custom-nodes\tools\

This is the DENO custom node tools folder. The installer should be handled here, not from a random folder.

2. Put and extract the ZIP here ...\deno-custom-nodes\tools\install_rtx_vfx_bat.zip

Move the downloaded ZIP into tools, then right-click it and choose Extract All.

3. Run only this file ...\deno-custom-nodes\tools\install_rtx_vfx.bat

If Windows creates an install_rtx_vfx_bat subfolder, open that subfolder and run the BAT inside it.

Step1

Open the install guide from the node

In ComfyUI, add (Deno) RTX Video Super Resolution. If NVIDIA RTX VFX is missing, click How to install.

Do thisClick How to install.
Check thisThis guide page opens in your browser.
Step2

Download the installer ZIP

Download install_rtx_vfx_bat.zip from the official Deno2026 GitHub link. It may first appear in your Windows Downloads folder.

Do thisClick the ZIP download link.
Check thisYou see install_rtx_vfx_bat.zip.
Step3

Move the ZIP into the DENO tools folder

Open your ComfyUI install, then open custom_nodes\deno-custom-nodes\tools\. Move install_rtx_vfx_bat.zip into that tools folder.

Do thisPut the ZIP inside deno-custom-nodes\tools.
Check thisThe ZIP is now next to OPEN_INSTALL_GUIDE.txt or other DENO tools files.
Step4

Extract the ZIP inside tools

In deno-custom-nodes\tools, right-click install_rtx_vfx_bat.zip, choose Extract All, then press Extract.

Do thisExtract the ZIP from inside the tools folder.
Check thisYou can now see install_rtx_vfx.bat, either directly in tools or in a new extracted subfolder.
Step5

Run the BAT from the DENO tools folder

Double-click install_rtx_vfx.bat from the extracted installer files inside deno-custom-nodes\tools. A black installer window opens.

Do thisRun ...\ComfyUI\custom_nodes\deno-custom-nodes\tools\install_rtx_vfx.bat, or the BAT inside the extracted folder under tools.
Check thisThe installer shows a Windows path for the ComfyUI app before asking for confirmation.
Step6

Confirm the shown ComfyUI location

The black installer window asks Install RTX VFX here? and shows a Windows path. Type Y only if that path is inside the same ComfyUI app you just closed. If it points somewhere unfamiliar, type N and stop.

Do thisLook for your ComfyUI folder name in the path, then type Y only when it matches.
Check thisSeeing python_embeded or python.exe is normal. The important part is that the path belongs to your ComfyUI install.
Step7

Wait for completion, then restart ComfyUI

When the installer says INSTALL COMPLETE, close the installer window and start ComfyUI again.

Do thisRestart ComfyUI completely.
Check thisRun the RTX node again. It should now load NVIDIA RTX VFX.
