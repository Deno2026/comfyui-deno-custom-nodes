Visual step-by-step guide for Windows users

Install DENO RTX VFX for ComfyUI without guessing paths

Use this page when the DENO RTX Video Super Resolution node says NVIDIA RTX VFX is missing. The screenshots below show exactly where the ZIP goes, where the BAT should run, and when it is safe to type Y.

Download installer ZIP
Close ComfyUI first.

The installer must run while every ComfyUI window and process is closed.

Use only this official ZIP.

Do not run BAT files from mirrors, reuploads, Discord attachments, or random websites.

Confirm the path before Y.

Type Y only when the installer points to the same ComfyUI app you just closed.

Follow this exact order

The important rule is simple: download the ZIP, move it into DENO's tools folder, extract it there, then run the BAT from there.

  1. 1
    Where the ZIP starts

    Windows usually downloads install_rtx_vfx_bat.zip into Downloads.

  2. 2
    Where the ZIP must go

    Move it into ComfyUI\custom_nodes\deno-custom-nodes\tools\.

  3. 3
    Where the BAT must run

    Run install_rtx_vfx.bat from the extracted installer files inside that same tools area.

1

Open the install guide from the RTX node

In ComfyUI, add (Deno) RTX Video Super Resolution. If NVIDIA RTX VFX is missing, click How to install.

Do thisClick How to install in the node panel.
Check thisThis visual install page opens in your browser.
2

Download the official installer ZIP

Download install_rtx_vfx_bat.zip from the official Deno2026 GitHub link. It may first appear in your Windows Downloads folder.

Do thisPress Download installer ZIP on this page.
Check thisYou can see install_rtx_vfx_bat.zip after the download finishes.
3

Move the ZIP into the DENO tools folder

Open your ComfyUI install, then open custom_nodes\deno-custom-nodes\tools\. Move install_rtx_vfx_bat.zip into that tools folder.

ComfyUI\custom_nodes\deno-custom-nodes\tools\install_rtx_vfx_bat.zip
Do thisDrag or copy the ZIP from Downloads into deno-custom-nodes\tools.
Check thisThe ZIP is now inside the DENO tools folder, not still sitting in Downloads.
4

Extract the ZIP inside the tools folder

In deno-custom-nodes\tools, right-click install_rtx_vfx_bat.zip, choose Extract All, then press Extract.

Do thisExtract the ZIP from inside deno-custom-nodes\tools.
Check thisYou can now see install_rtx_vfx.bat, either directly in tools or inside a new extracted subfolder.
5

Run install_rtx_vfx.bat from that extracted folder

Double-click install_rtx_vfx.bat from the extracted installer files inside the DENO tools area. A black Command Prompt installer window opens.

...\ComfyUI\custom_nodes\deno-custom-nodes\tools\install_rtx_vfx.bat
Do thisRun only the BAT that came from the official ZIP and was extracted inside the DENO tools folder.
Check thisThe black installer window shows a ComfyUI path before it asks for confirmation.
6

Confirm the shown ComfyUI location before typing Y

The installer asks Install RTX VFX here? and shows a Windows path. Type Y only if that path is inside the same ComfyUI app you just closed. If it points somewhere unfamiliar, type N and stop.

Do thisLook for your ComfyUI folder name in the shown path, then type Y only when it matches.
Check thisSeeing python_embeded or python.exe is normal. The important part is that the path belongs to your ComfyUI install.
7

Wait for INSTALL COMPLETE, then restart ComfyUI

When the installer says INSTALL COMPLETE, close the installer window and start ComfyUI again.

Do thisRestart ComfyUI completely after the installer finishes.
Check thisRun the RTX node again. It should now load NVIDIA RTX VFX.
