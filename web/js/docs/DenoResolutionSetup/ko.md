# (Deno) Resize Box

모델에 맞는 출력 크기를 정하고, 입력 이미지를 그 프레임에 맞게 리사이즈합니다.

## Crop Position (Fill)

이미지를 연결하면 노드 미리보기에서 원본 전체를 볼 수 있습니다.

- 크롭 박스 안을 드래그하면 사용할 영역을 이동할 수 있습니다.
- 어느 모서리든 드래그하면 선택한 화면 비율을 유지한 채 확대하거나 축소할 수 있습니다.
- 크롭을 편집해도 출력 메가픽셀, 가로, 세로 크기는 바뀌지 않습니다.
- 크롭 위치와 확대 값은 워크플로우에 함께 저장됩니다.

너무 작은 영역을 선택하면 최종 출력 크기로 확대되는 과정에서 이미지가 부드러워질 수 있습니다.

## 다른 리사이즈 방식

- `Center Crop (Fill)`은 프레임을 채우고 가운데를 기준으로 자릅니다.
- `Fit (Letterbox/Pillarbox)`은 원본 전체를 유지하고 필요한 곳에 검은 여백을 넣습니다.

출력은 리사이즈된 `image`와 최종 `width`, `height`입니다.
